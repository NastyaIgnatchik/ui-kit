
# UI Kit

### Requirements

- Node.js 24+
- npm

## Installation

Install dependencies from the project root:

```bash
npm install
```
## Run

Run the whole project:

```bash
npm run dev
```
Run storybook:

```bash
npm run Storybook
```

## Build

Build the whole project:

```bash
npm run build
```

## Tests

Run component tests:

```bash
npm run test
```

## Versioning

Create a changeset:

```bash
npm run changeset
```

Apply version changes:

```bash
npm run version
```
